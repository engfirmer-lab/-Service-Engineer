💾 สำรองข้อมูลทั้งระบบ — เน้น Troubleshooting เป็นหลัก

แก้ไขได้เฉพาะ Super Admin เท่านั้น — ระบบจะเช็คทุกชั่วโมงว่าถึงเวลาตามที่ตั้งไว้หรือยัง

เปิดใช้งาน Backup อัตโนมัติ

สถานะ Backup อัตโนมัติล่าสุด

กดเช็คว่าครั้งล่าสุดสำเร็จหรือไม่ (ต้องขอสิทธิ์ Google Drive ก่อน จึงให้กดเช็คเองแทนที่จะเช็คอัตโนมัติ)

สำรองข้อมูล (Backup)

ดึงข้อมูลทั้งหมดจาก Firestore ณ ตอนนี้ เก็บไว้เป็นสำรองส่วนตัว — เน้น Error Code, อาการเสีย, วิธีการ, อุปกรณ์ที่ใช้, อะไหล่ที่ใช้, เวลาที่ใช้ ส่วนข้อมูลอื่น (เอกสาร) จะแสดงเป็นลิงก์อ้างอิงเท่านั้น

Export ประวัติการใช้งาน (Log)

บันทึกเฉพาะการกระทำสำคัญ (ลบ, ดาวน์โหลด Backup, แก้ไขสิทธิ์) ไม่บันทึกทุกคลิก — เก็บไว้ตลอดไป เห็นเฉพาะ Super Admin เท่านั้น

เอกสารทางเทคนิค (สำหรับแก้ไขโค้ดในอนาคต)

สรุปไว้ให้กลับมาแก้ไขโค้ดได้ง่ายขึ้น เห็นเฉพาะ Super Admin เท่านั้น

การใช้งานพื้นที่

Firestore (ฐานข้อมูลหลัก)

⚠️ ตัวเลขนี้เป็นการประมาณการจากจำนวน/ขนาดข้อมูลในระบบตอนนี้เท่านั้น ไม่ใช่ตัวเลขจริงจาก Google 100% — ดูตัวเลขที่แม่นยำได้ที่ Firebase Console เท่านั้น — กดเช็คเองเพื่อประหยัดโควต้า (ใช้เล็กน้อยทุกครั้งที่เช็ค)

Google Drive (โฟลเดอร์ "Service Center" ทั้งหมด)

✓ ตัวเลขนี้เป็นขนาดไฟล์จริงของโฟลเดอร์ "Service Center" ทั้งก้อน — รวมทุกไฟล์ข้างในไม่ว่าจะมาจากไหน (รูป/วิดีโอ/เอกสารที่อัปโหลดผ่านแอป, ไฟล์ Backup รายวัน, หรือไฟล์ที่วางไว้เองโดยตรงใน Drive) — ไม่นับเอกสารที่แค่แปะลิงก์ไปที่อื่นภายนอกโฟลเดอร์นี้ (ไม่สามารถทราบขนาดได้ ต้องไปตรวจสอบที่ต้นทางเอง) — กดเช็คเองเพราะต้องไล่ดูทุกโฟลเดอร์ อาจใช้เวลาสักครู่
